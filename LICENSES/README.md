# Bundled Tool Licenses

Release archives include downloaded sidecar binaries listed in
`scripts/sidecar-manifest.txt`. macOS FFmpeg and FFprobe are built by
`scripts/fetch-sidecars.sh` from the pinned official FFmpeg source tarball.

- FFmpeg / FFprobe license details: https://ffmpeg.org/legal.html
- yt-dlp license: https://github.com/yt-dlp/yt-dlp/blob/master/LICENSE
